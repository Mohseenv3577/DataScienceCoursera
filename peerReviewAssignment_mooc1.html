7. Joining data with SQL (6 points)¶

In a new code cell use Python to run a SQL query that joins data from the three tables listed below and converts it into a DataFrame, df. Display the first five rows of df.

  • Customer_Ownership: purchase date, purchase price, date that the warranty expired for people that purchased their cars in 2023
  • Dealers: name and address
  • Customers: customer's first name, last name, household income
In [27]:
query = """
SELECT
co.purchase_date,
co.purchase_price,
co.warranty_expire_date,
d.dealer_name,
d.dealer_address,
c.first_name,
c.last_name,
c.household_income
FROM Customer_Ownership co
JOIN Dealers d
ON co.dealer_id = d.dealer_id
JOIN Customers c
ON co.customer_id = c.customer_id
WHERE strftime('%Y', co.purchase_date) = '2023';
"""
df = pd.read_sql(query, conn)
